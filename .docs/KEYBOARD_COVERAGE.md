# Keyboard navigation coverage (1.5.2, D-093)

Written for the developer and the owner's tester. It records how each screen is used from the keyboard and how that was checked.

## The shared behaviour (every screen)

| Where                                                                  | Keys                                                                                                                                                                                     | Source                                                   |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| Every control                                                          | Tab / Shift+Tab in reading order (right to left); a visible focus ring (`:focus-visible`)                                                                                                | `styles/base.css`, `components.css`                      |
| Every window                                                           | Focus goes in (first field, else Cancel); Tab stays inside; Esc closes, asking first if something was typed; focus returns to the button that opened it; arrows move between its buttons | `lib/modalChrome.js` (D-065)                             |
| Forms that move money or stock (`data-enter-step`)                     | Enter goes to the next field, then to the confirm button; only Enter on that button confirms, so a stray Enter never pays twice                                                          | `lib/keyboard.js` (D-065)                                |
| Clickable table rows (`rowKeys`)                                       | Tab reaches the row; Enter or Space opens it; ↑ ↓ move between rows                                                                                                                      | `lib/keyboard.js`                                        |
| Choice groups: segmented radios, tabs, menus, the sidebar, button rows | ← → (right to left: ← is next) or ↑ ↓; Home / End; radios and tabs are chosen as they are reached; menus and the sidebar open with Enter                                                 | `lib/keyboard.js` `roveArrows` (1.5.2)                   |
| Text fields                                                            | Keep their own arrows, Home and End; no shortcut acts while typing                                                                                                                       | `roveArrows` and `useKeyboardShortcuts` skip text fields |
| Scanner                                                                | Scans are recognised by timing and written into the scan field (`useBarcode`, unchanged); no list opens during a scan                                                                    | `hooks/useBarcode.js`, `scannerTiming.js`                |

## Limits

- Keys were simulated by Playwright in the development build. A physical scanner and keyboard should be tried once at the shop.
- Radio groups keep every option in the Tab order (no roving tab stop). Tab passes through each option; the arrows also choose.
