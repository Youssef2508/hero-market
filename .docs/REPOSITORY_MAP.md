## Where to change things

- A colour, radius, font size or spacing → `styles/tokens.css` (never in components).
- A shared control's look → `styles/components.css` (+ `components/ui/*` if markup changes).
- Navigation entries / permissions → `components/shell/navigation.js`.
- Cashier layout → `components/pos/CheckoutTerminal.jsx` + `styles/pos.css`.
- A business rule → the owning hook in `hooks/` (see `BUSINESS_LOGIC.md`), never in a component.
- A new IPC capability → `src/main/index.js` + `src/preload/index.js` + document in `API_AND_INTEGRATIONS.md`.
- Database schema → `src/main/db.js#initializeDatabase` (additive migration) **and** `scripts/init-dev-db.js`.
