## Renderer (`src/renderer/src`)

| Path                               | Responsibility                                                                                            |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `main.jsx`, `App.jsx`              | Mount; composition root (start-up gate, lock, shell, dialogs, audit timer, session expiry)                |
| `lib/api.js`                       | `api(op, body)`, `ApiError`, `can(user, permission)`, `newClientRef()`                                    |
| `lib/dao/`                         | Thin wrappers for tills and logs operations                                                               |
| `lib/printTemplates.js`            | Legacy sale-receipt HTML (reprints; reference for the receipt tests)                                      |
| `lib/utils.js`                     | `normalizeDigits`, `playSound`, dates, `round2`, `formatMoney`, friendly errors                           |
| `hooks/`                           | Screen controllers. They call the service; business rules live in the service.                            |
| `components/setup/StartupGate.jsx` | Connection (three device roles) and first-run administrator                                               |
| `components/shell/`                | `AppShell`, `Sidebar`, `Topbar`, `navigation.js` (items + required permissions)                           |
| `components/pos/`                  | `CheckoutTerminal`, `LockScreen`                                                                          |
| `components/admin/`                | One file per management screen, incl. `RolesTab`, `SettingsTab`, `ReceiptDesignerTab`, `AdminDashboard`   |
| `components/modals/`               | Dialogs (`AppModals` mounts the shared ones)                                                              |
| `components/ui/`                   | Shared primitives (`StatCard`, `EmptyState`, `SortableTh`, `Pagination`, `Timestamp`, `BidiText`, charts) |
| `styles/`, `theme/`                | Design tokens and component styles; light/dark theme provider                                             |

## Where to change things

| To change…                     | Edit                                                                                                                         |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| A business rule or calculation | The service module in `src/server/modules/` (never the renderer); add a test in `tests/service/`                             |
| A permission                   | `src/server/auth/permissions.js`, the operation's `permission`, and the navigation entry in `components/shell/navigation.js` |
| The database schema            | A **new** file in `src/server/db/migrations/` (never edit an applied one); update [DATA_MODEL.md](DATA_MODEL.md)             |
| The receipt layout engine      | `src/shared/receipt.mjs`, `resources/print_receipt.ps1` and the designer preview together; run the golden tests              |
| A printed report               | `src/shared/reportLines.mjs`                                                                                                 |
| Colours, spacing, fonts        | `styles/tokens.css`                                                                                                          |
| A new IPC capability           | `src/main/*` + `src/preload/index.js`, documented in [API_AND_INTEGRATIONS.md](API_AND_INTEGRATIONS.md)                      |
